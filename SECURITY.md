# Security Policy

## Reporting a Vulnerability

**Do not file security issues on the public issue tracker.**

Please report security vulnerabilities by email to Devstroop Technologies:

- **Email:** `info@devstroop.com`
- **Subject prefix:** `[SECURITY] agent-cli`
- **Include:**
  - Affected version
  - Target platform
  - Steps to reproduce
  - Suggested fix (if you have one)

### What to expect

- **Acknowledgement:** within 7 business days
- **High-severity fix:** within 30 calendar days, or a "won't fix with rationale" response
- **Lower-severity:** may take longer; timelines communicated by email

No bug bounty is offered at this time.

### Disclosure

Public disclosure 90 days from initial report, or upon release of a fix, whichever is earlier.
